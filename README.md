# LEO Developments, Chairman's Growth Strategy

A research-grounded, mobile-friendly executive strategy hub for LEO Developments, VISTAL by Victoria Swarovski, and Rove Home Muscat Central. Prepared as an internal strategic proposal, snapshot **03 November 2026**.

## Site
- `index.html`, 19 linked strategy chapters (including requested India, Iran, Russians in Dubai, UAE expatriates and the additional DACH hypothesis).
- `styles.css`, warm charcoal and gold design system adapted from Al Jadeed, with a single consolidated LEO presentation layout layer, responsive compact chapter rail, centered editorial sections, readable card typography and print styles.
- `app.js`, current-chapter tracking, chapter dropdown, mobile drawer with scroll lock, progress, reduced-motion-aware dot navigation, presentation mode, print and interactive illustrative funnel scenario.

## Publishing on GitHub Pages
1. Open **Repository → Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch** if not configured.
3. Choose **main** and **/(root)**, then save.
4. The published URL is expected to be: https://my-ai-marketing.github.io/leo/

GitHub Pages settings and publication must be verified in the repository's GitHub interface. Committing files does not necessarily enable Pages for a newly initialized repository.

## Editorial and data controls
- This is a **static research/strategy dashboard**, not a live CRM integration.
- The interactive planner is illustrative, not actual LEO sales data.
- Public claims are sourced inside the final section; proposed market tactics are hypotheses until validated.
- All developer-brand and residency claims require authorized review before external reuse.
- Do not add private CRM exports, customer lists, personal data or confidential commercial figures: **GitHub Pages is publicly reachable**. The `noindex` directive does not create access controls.
- Do not collect or buy real-estate owner records without a valid lawful purpose and appropriate permissions; use compliant partner introductions instead.
